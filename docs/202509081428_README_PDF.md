## 🎯 Comment obtenir le PDF

### Option 1 : Imprimer depuis le navigateur (RECOMMANDÉE)
1. Le fichier HTML s'est ouvert automatiquement dans votre navigateur
2. Utilisez `Cmd+P` (macOS) ou `Ctrl+P` (Windows/Linux)
3. Sélectionnez "Enregistrer au format PDF"
4. Sauvegardez sous le nom `SCHEMA_HABILETE_MATHS.pdf`

### Option 2 : Conversion en ligne
1. Allez sur https://www.markdowntopdf.com/
2. Uploadez le fichier `SCHEMA_HABILETE_MATHS_CLEAN.md`
3. Téléchargez le PDF généré

### Option 3 : Avec un éditeur Markdown
1. Ouvrez `SCHEMA_HABILETE_MATHS.md` dans Typora, Mark Text, ou VS Code
2. Utilisez la fonction "Exporter vers PDF"
