❓ Questions Fréquentes

Comment fonctionne le système de notes ?

Luchy calcule automatiquement vos notes sur 20 basées sur le nombre de bonnes réponses. Vos performances sont sauvegardées localement et visibles dans le "Bulletin de Notes".

Mes données sont-elles sécurisées ?

Oui ! Toutes vos données restent sur votre appareil. Aucune information n'est envoyée vers nos serveurs. Votre vie privée est totalement respectée.

Comment changer la difficulté des puzzles ?

Utilisez les flèches haut/bas dans la barre d'outils pour ajuster la difficulté de 2x2 à 6x6 pièces selon votre niveau.

Puis-je utiliser l'app sans internet ?

Absolument ! Luchy fonctionne entièrement hors ligne. Toutes les fonctionnalités sont disponibles sans connexion internet.

Comment réinitialiser mes scores ?

Dans le "Bulletin de Notes", vous pouvez supprimer vos statistiques individuelles. Pour une réinitialisation complète, désinstallez et réinstallez l'app.
