# Politique de Confidentialité - Luchy

**Dernière mise à jour : 29 septembre 2025**

## 1. Introduction

Luchy ("nous", "notre", "nos") s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations personnelles lorsque vous utilisez notre application mobile Luchy.

## 2. Informations que nous collectons

### 2.1 Informations de l'appareil
- **Identifiant unique de l'appareil** : Pour le fonctionnement de l'application
- **Informations système** : Version iOS/Android, modèle d'appareil
- **Données de performance** : Statistiques d'utilisation anonymes

### 2.2 Données éducatives
- **Scores d'évaluations** : Notes sur 20 pour les quiz et évaluations
- **Progression** : Niveaux atteints dans les habiletés mathématiques
- **Temps de performance** : Temps mis pour compléter les évaluations
- **Historique des sessions** : Dates et résultats des évaluations

### 2.3 Données de jeu
- **Images sélectionnées** : Choix d'images pour les puzzles
- **Statistiques de jeu** : Nombre de coups, difficulté des puzzles
- **Préférences** : Paramètres de l'application

## 3. Comment nous utilisons vos informations

### 3.1 Fonctionnalités principales
- **Suivi de progression** : Affichage du bulletin de notes et statistiques
- **Personnalisation** : Adaptation du contenu selon le niveau
- **Sauvegarde locale** : Stockage des données sur votre appareil

### 3.2 Amélioration de l'application
- **Analyses anonymes** : Compréhension de l'utilisation pour améliorer l'app
- **Correction de bugs** : Identification et résolution des problèmes

## 4. Stockage des données

### 4.1 Stockage local
- **Base de données SQLite** : Toutes vos données sont stockées localement sur votre appareil
- **Aucune transmission** : Vos données ne quittent jamais votre appareil
- **Contrôle total** : Vous gardez le contrôle de vos données

### 4.2 Sécurité
- **Chiffrement local** : Données protégées par le système d'exploitation
- **Accès restreint** : Seule l'application Luchy peut accéder à vos données

## 5. Partage d'informations

### 5.1 Aucun partage externe
- **Pas de vente** : Nous ne vendons jamais vos données
- **Pas de partage** : Vos données ne sont pas partagées avec des tiers
- **Pas de publicité** : Aucune donnée utilisée pour la publicité

### 5.2 Exceptions légales
- **Obligation légale** : Seulement si requis par la loi
- **Protection des droits** : Pour protéger nos droits légaux

## 6. Droits des utilisateurs

### 6.1 Accès et contrôle
- **Visualisation** : Consultez vos données via le bulletin de notes
- **Suppression** : Supprimez vos données via les paramètres de l'app
- **Export** : Vos données restent sur votre appareil

### 6.2 Modifications
- **Mise à jour** : Vous pouvez modifier vos préférences à tout moment
- **Désinstallation** : Suppression complète en désinstallant l'app

## 7. Protection des enfants

### 7.1 Conformité COPPA
- **Aucune collecte** : Nous ne collectons pas d'informations personnelles d'enfants
- **Données locales uniquement** : Toutes les données restent sur l'appareil
- **Contrôle parental** : Les parents gardent le contrôle total

### 7.2 Sécurité des enfants
- **Contenu éducatif** : Application entièrement éducative et sûre
- **Pas de communication** : Aucune fonction de chat ou de communication
- **Pas de géolocalisation** : Aucun suivi de localisation

## 8. Modifications de cette politique

### 8.1 Notification des changements
- **Mise à jour de l'app** : Les modifications seront incluses dans les mises à jour
- **Date de modification** : Toujours indiquée en haut de ce document

### 8.2 Acceptation
- **Utilisation continue** : L'utilisation de l'app après modification = acceptation
- **Désinstallation** : Option de désinstaller si vous n'acceptez pas les changements

## 9. Contact

### 9.1 Questions sur la confidentialité
- **Email** : privacy@luchy.app
- **Support** : Via les paramètres de l'application

### 9.2 Réclamations
- **Réponse rapide** : Nous répondons dans les 48h
- **Résolution** : Engagement à résoudre tous les problèmes

## 10. Conformité légale

### 10.1 Réglementations respectées
- **RGPD** : Conformité avec le Règlement Général sur la Protection des Données
- **COPPA** : Conformité avec la loi américaine sur la protection des enfants
- **Loi française** : Respect de la législation française sur la protection des données

### 10.2 Transparence
- **Politique claire** : Langage simple et compréhensible
- **Mise à jour régulière** : Révision annuelle de cette politique
